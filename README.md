# sound-keyboard

## Pin wiring guide

| GPIO Pin | Function    | Notes                                                   |
|----------|-------------|---------------------------------------------------------|
| 21       | Status LED  | Active high. Change if your board uses a different pin. |
| 5        | Encoder CLK | -                                                       |
| 6        | Encoder DT  | -                                                       |
| 1        | Skip Back   | Wire between pin and GND.                               |
| 2        | Skip Ahead  | Wire between pin and GND.                               |
| 3        | Mute        | Wire between pin and GND.                               |
| 4        | Pause       | Wire between pin and GND.                               |
